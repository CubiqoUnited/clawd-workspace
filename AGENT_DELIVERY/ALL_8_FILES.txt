## Setup Instructions

1. **Copy all files** to your Next.js project at the paths above
2. **Wrap your app** with AgentProvider in app/layout.tsx:

```tsx
import { AgentProvider } from '@/contexts/AgentContext';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <AgentProvider>
          {children}
        </AgentProvider>
      </body>
    </html>
  );
}
```

3. **Use in components**:

```tsx
import { useAgent } from '@/hooks/useAgent';

export default function MyComponent() {
  const { runTask, isRunning, enabledTools } = useAgent();
  
  return (
    <button onClick={() => runTask("Search for TypeScript best practices")}>
      Run Task
    </button>
  );
}
```

---

All files are TypeScript, use Tailwind for styling, and have no external dependencies beyond Next.js/React.
