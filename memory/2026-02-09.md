## Lessons Learned

### Vercel Authentication:
- Authentication is a project-level setting in Vercel
- Not controlled by `vercel.json` or environment variables
- Must be disabled in dashboard: Settings → Authentication
- Causes 401 Unauthorized for public users

### React Deployment Issues:
- CSS animations can work while React fails (hydration errors)
- Browser cache can persist broken JavaScript bundles
- Hard refresh (Ctrl+Shift+R) often fixes React hydration issues
- Incognito mode tests without extensions/cache interference

### User Communication:

- "Animation on left, blank screen" indicated CSS working, React failing
