## 🎨 What Is Branchy?

**Concept:** A friendly tree-like creature whose branches represent subdomains

**Key Features:**
- **5 color-coded states** matching Cubiqo's RGY system:
  - Green = Active/Healthy
  - Yellow = Warning/Pending
  - Red = Error/Critical
  - Blue = Focused/Professional
  - Base = Neutral/Ready
- **Scalable design** from tiny 16x16 icons to hero images
- **Animated SVG** with embedded animations (no dependencies)
- **Accessibility-first** with ARIA labels, keyboard nav, screen reader support
- **Framework-agnostic** works with React, Vue, vanilla JS

## 💡 Why This Works

1. **Visual Metaphor:** Tree branches = domain branching structure (intuitive)
2. **Reduces Intimidation:** Friendly character makes technical features approachable
3. **Instant Status:** Color-coded states provide immediate feedback
4. **Memorable Branding:** Creates strong association with sub-domains feature
5. **Production Ready:** All code/assets optimized and documented
