# Alex's E-commerce Template (Next.js)

Clean, simple, and effective e-commerce template built with Next.js 14. Perfect for quick deployment with all essential e-commerce features.

## Features

### 🛒 E-commerce Essentials
- Product grid with images
- Shopping cart with localStorage
- Add/remove/update quantity
- Checkout functionality
- Order management

### 🔍 SEO Optimized
- Next.js 14 with App Router
- Server-side rendering
- Automatic SEO meta tags
- Sitemap generation
- Fast page loads

### 🎨 Clean UI
- Simple, clean design
- Responsive layout
- Easy customization
- Light/dark mode ready

### 🚀 Performance
- Image optimization
- Code splitting
- Fast loading
- Mobile-first

### 📱 Integrations Ready
- Shopify/Printify ready
- Payment processing
- Analytics
- Email marketing

## Quick Start

1. Clone template
2. `npm install`
3. `npm run dev`
4. Deploy to Vercel

Perfect for quick e-commerce sites with all the essentials.
