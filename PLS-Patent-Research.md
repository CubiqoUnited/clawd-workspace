### **2. Alice/101 Analysis for PLS**

**Alice Test (Two-Step Framework):**

**Step 1: Is the claim directed to a patent-ineligible concept?**
- **Abstract Idea Risk:** "Verifying service performance" could be considered abstract
- **BUT:** PLS adds specific technical improvements:
  - Cryptographic binding of RP hash
  - Windowed token processing
  - Hardware sensor integration
  - Real-time attestation

**Step 2: Does the claim add significantly more?**
- **YES - Technical Improvements:**
  1. **Specific Algorithm:** "IMU windowing (1.0s window / 0.25s hop)"
  2. **Hardware Integration:** Device-protected keys, sensor arrays
  3. **Novel Data Structure:** Merkle tree over token windows
  4. **System Integration:** Payment escrow tied to performance bands
