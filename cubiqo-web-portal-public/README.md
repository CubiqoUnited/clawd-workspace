# CubiQo Web Portal

Visual website builder platform inspired by modularapp.preview.emergentagent.com.

## 🚀 Features

- **Visual Designer** - Drag-and-drop interface with live preview
- **One-Click Deployment** - Deploy to Vercel, Netlify, GitHub Pages
- **SEO Automation** - Automatic meta tags, sitemaps, optimization
- **Analytics Dashboard** - Google Analytics integration
- **A/B Testing** - Test designs with statistical analysis
- **Growth Tools** - Email marketing, social media integration

## 🎯 What It Is

A no-code website builder platform where users can:
1. Choose from professional templates
2. Drag-and-drop components
3. Configure SEO and analytics
4. Deploy with one click
5. Track performance and growth

## 🛠️ Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js for 3D animations

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/cubiqo-web-portal.git

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the web portal.
