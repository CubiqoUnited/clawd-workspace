# RGY Side Panel - Quick Start Guide

## What is the RGY Side Panel?

The RGY Side Panel is a keyword management interface for Cubiqo that helps you organize your interests and preferences across three color zones:

- 🔴 **Red Zone**: Dating, relationships, and personal connections
- 🟡 **Yellow Zone**: Friends, social activities, and casual hangouts
- 🟢 **Green Zone**: Work, professional networking, and wellness

## How to Use

### Viewing the Demo

1. Open `side-panel.html` in any modern web browser
2. You'll see the side panel with three color zones
3. Each zone can be expanded by clicking on it

### Adding Keywords

**Method 1: Using the Add Button**
1. Click on a color zone to expand it
2. Type your keyword in the text box
3. Click the "Add" button
4. Your keyword appears as a tag

**Method 2: Using Enter Key**
1. Click on a color zone to expand it
2. Type your keyword in the text box
3. Press Enter on your keyboard
4. Your keyword appears as a tag

### Removing Keywords

1. Find the keyword tag you want to remove
2. Click the "×" button on the tag
3. The keyword is removed immediately

## Understanding the Colors

### 🔴 Red Zone
**Purpose**: Intimate and personal connections

Use this for keywords related to:
- Dating and romance
- Adult content preferences
- Personal indulgences
- Intimate activities

**Example**: If you're interested in romantic dinners and wine tasting, add those keywords here.

### 🟡 Yellow Zone
**Purpose**: Social and platonic relationships

Use this for keywords related to:
- Friendship activities
- Casual hangouts
- Social events
- Fun hobbies

**Example**: If you enjoy board game nights and coffee shop meetups, add those keywords here.

### 🟢 Green Zone
**Purpose**: Professional and personal growth

Use this for keywords related to:
- Career and work
- Professional networking
- Health and wellness
- Learning and achievement

**Example**: If you're a freelance developer interested in yoga, add those keywords here.

### 4. You're in Control

## Tips for Best Results

### Do's ✅
- **Be specific**: "Italian restaurants" is better than just "food"
- **Use multiple keywords**: Mix broad and specific terms
- **Update regularly**: Add new interests as they develop
- **Use different zones**: Spread keywords across appropriate colors

### Don'ts ❌
- **Don't use the same keyword in multiple zones**: Pick the best fit
- **Don't be too vague**: "stuff" or "things" won't help matching
- **Don't add too many**: Quality over quantity (5-10 per zone is ideal)
- **Don't forget to remove outdated ones**: Keep your list current

## Troubleshooting

### Problem: I can't add a keyword
**Solution**: Check if:
- The keyword already exists in that zone (duplicates aren't allowed)
- The input field is empty (empty keywords are ignored)
- You've typed the keyword correctly

### Problem: My keywords disappeared after closing the browser
**Solution**: 
- Keywords are saved automatically to your browser's storage
- If using private/incognito mode, keywords won't persist
- Clear your browser data carefully to avoid losing keywords

### Problem: The panel doesn't fit on my screen
**Solution**:
- The panel is responsive and adapts to screen size
- On mobile, the panel takes full width
- Try zooming out (Ctrl/Cmd + Minus) if needed

### Problem: I want to start over with fresh keywords
**Solution**:
1. Remove all keywords manually, or
2. Clear your browser's localStorage for this site, or
3. Use private/incognito mode for a fresh start
