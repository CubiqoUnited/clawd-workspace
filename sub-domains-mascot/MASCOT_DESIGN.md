# Sub-Domains Mascot Design: "Branchy"

## Concept Overview
**Name:** Branchy (The Branch Creature)  
**Role:** Visual representative of the sub-domains system  
**Personality:** Helpful, organized, growth-oriented, connector

## Visual Description

### Core Design
Branchy is a small, friendly tree-like creature that embodies the concept of branching domains and hierarchical structures.

**Key Features:**
- **Body:** Rounded, organic shape resembling a tree trunk/node
- **Branches:** 3-5 flexible branch-like appendages extending from the body
- **Face:** Simple, friendly expression with two dot eyes and a small smile
- **Color Scheme:** Matches Cubiqo's RGY (Red/Yellow/Green) system
- **Size:** Compact and cute, fits well in UI elements

### Design Philosophy
1. **Branching Structure:** Represents how subdomains branch from main domains
2. **Connectedness:** Multiple branches show interconnection
3. **Growth:** Tree-like nature implies expansion and development
4. **Modularity:** Each branch can represent a different subdomain
5. **Friendly:** Approachable design reduces complexity intimidation

## Color States (RGY Integration)

### Green State (Active/Ready)
- **Primary Color:** #2ECC71 (vibrant green)
- **Meaning:** Domain is active and functioning
- **Branches:** Full color, energetic posture
- **Expression:** Happy, eyes wide open

### Yellow State (Pending/Warning)
- **Primary Color:** #F39C12 (warm yellow/amber)
- **Meaning:** Domain needs attention or is processing
- **Branches:** Slightly dimmed, cautious posture
- **Expression:** Thoughtful, one eye squinting

### Red State (Critical/Error)
- **Primary Color:** #E74C3C (urgent red)
- **Meaning:** Domain has issues requiring immediate action
- **Branches:** Alert posture, some branches pointing
- **Expression:** Concerned, alert eyes

### Blue State (Focused/Professional)
- **Primary Color:** #3498DB (cool blue)
- **Meaning:** Professional/business subdomain
- **Branches:** Organized, structured arrangement
- **Expression:** Focused, determined

## Animations

### Idle Animation
- Gentle sway of branches
- Occasional blink
- Subtle breathing motion (body expands/contracts)

### Creation Animation
- Branches grow from body one by one
- Sparkle effect as each branch appears
- Final pose with all branches extended

### Connection Animation
- Branches extend toward other Branchies
- Glowing connection lines form between creatures
- Synchronized pulse when connected

### Error Animation
- Branches droop slightly
- Red warning pulse
- Question mark or exclamation appears above head

### Success Animation
- Branches wave happily
- Celebratory sparkles
- Body bounces slightly

## Size Variations

### Tiny (Icon Size: 16x16 - 32x32px)
- Simplified design
- 2-3 branches maximum
- Minimal facial features
- High contrast colors

### Small (UI Element: 64x64 - 128x128px)
- Standard detail level
- Full facial expression
- 3-4 branches
- Suitable for buttons, cards

### Medium (Feature Display: 256x256 - 512x512px)
- High detail rendering
- All animations supported
- Full color gradients
- Drop shadows and effects

### Large (Hero/Marketing: 1024x1024px+)
- Maximum detail
- Texture and depth
- Complex lighting
- Suitable for promotional materials

## Use Cases

### 1. Subdomain Creation Interface
- Branchy appears when creating new subdomain
- New branch grows to represent the new subdomain
- Color indicates status of creation process

### 2. Domain Dashboard
- Multiple Branchies represent different domains
- Hover shows domain details
- Click to manage domain

### 3. Connection Visualization
- Branchies connect via branches when domains link
- Network visualization of domain structure
- Interactive relationship mapping

### 4. Status Indicators
- Small Branchy icon in corner shows overall health
- Color changes based on system status
- Notification badge on branches for alerts

### 5. Onboarding/Tutorial
- Branchy guides new users through setup
- Speech bubble with helpful tips
- Animated demonstrations

### 6. Loading States
- Branchy's branches rotate while loading
- Progress indicated by branch illumination
- Friendly alternative to spinner

## Technical Implementation Notes

### SVG Format (Recommended)
- Scalable to any size
- Small file size
- Animatable via CSS/JS
- Supports color theming

### File Structure
```
/assets/mascot/
  ├── branchy-base.svg          # Base design
  ├── branchy-green.svg         # Active state
  ├── branchy-yellow.svg        # Warning state
  ├── branchy-red.svg           # Error state
  ├── branchy-blue.svg          # Focus state
  ├── branchy-animated.json     # Lottie animation
  └── branchy-spritesheet.png   # Fallback raster
```

### Animation Library Options
- **Lottie:** For complex animations
- **CSS Animations:** For simple transitions
- **GSAP:** For interactive animations
- **Canvas:** For particle effects

## Accessibility Considerations

- **High Contrast Mode:** Simplified color scheme with clear boundaries
- **Reduced Motion:** Static poses instead of animations
- **Screen Readers:** Alt text describes state and purpose
- **Color Blindness:** Uses patterns in addition to color
- **Focus Indicators:** Clear visual feedback for keyboard navigation

Branchy is more than decoration—it's a visual language that makes sub-domains approachable, memorable, and engaging. The design balances professionalism with personality, creating a friendly guide through potentially complex domain management tasks.
