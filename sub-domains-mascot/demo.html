Use Cases

🚀 Subdomain Creation

Branchy appears when creating a new subdomain. A new branch grows to represent the new subdomain, with color indicating the status of the creation process.

📊 Domain Dashboard

Multiple Branchies represent different domains. Hover to see domain details, click to manage. Visual clustering shows related subdomains.

🔗 Connection Visualization

Branchies connect via animated branches when domains are linked. Interactive network visualization of your entire domain structure.

⚠️ Status Indicators

Small Branchy icon in the corner shows overall system health. Color changes based on system status, with notification badges on branches for alerts.

🎓 Onboarding & Tutorials

Branchy guides new users through subdomain setup with speech bubbles containing helpful tips and animated demonstrations.

⏳ Loading States

Branchy's branches gently rotate while loading. Progress is indicated by sequential branch illumination - a friendly alternative to boring spinners.
