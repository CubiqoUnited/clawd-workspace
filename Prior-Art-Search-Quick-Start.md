## 🎯 **WHAT TO LOOK FOR**

### **Red Flags (High Risk):**
- Patents with "windowed token extraction"
- Patents combining "crypto + sensors + payments"
- Patents mentioning "Merkle tree attestation"
- Patents about "service performance without storage"

### **Green Flags (Low Risk):**
- Patents only about digital content verification
- Patents without payment integration
- Patents requiring raw data storage
- Patents not using sensor data
